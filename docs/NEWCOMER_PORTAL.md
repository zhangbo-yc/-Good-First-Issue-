# 开源起点：新人项目门户

## 使用

运行 `.\.venv\Scripts\python.exe serve.py`，打开 `http://127.0.0.1:8503/`。

从项目广场预览项目用途、方向与具体任务，进入项目后可搜索、筛选和翻页；贡献指引与具体任务分开。任务页优先展示中文说明，再按已有资料展示技术用途、适合背景、阶段理由、进入条件、开始步骤、验收建议和代码入口。模型分析可展示固定仓库中的源码/测试引用，并把材料明示、依据证据推断和建议验证项分开标注。新增“研究方法”页说明A/B/C/D实验条件、样本量与模型辅助评分边界。

界面不显示评论、原始JSON、内部证据包或认领/关闭状态。源码证据以可读的GitHub文件路径和行号链接展示。所有任务统一按开放、待解决呈现，原始快照不修改。

## DeepSeek集成

用户授权的密钥保存在`.env`，该文件已被`.gitignore`排除。`.env.example`提供不含密钥的配置示例。服务、批量导读、旧分析CLI均支持读取该配置，已有环境变量优先。服务公开接口只返回是否配置，不返回凭据。默认仅监听本机，并校验请求Host/Origin。

`prepare_newcomer.py`读取全量Issue标题和正文，每批真实调用DeepSeek，校验ID集合、中文内容、开放状态口径与次要信息过滤。结果逐批原子保存，绑定标题/正文哈希、提示版本、模型与来源；失败任务可重跑，其余命中缓存。产物位于`data/<repo>/newcomer_summaries.json`，调用收据位于`data/newcomer_runs/`。

`prepare_deep_guides.py`复用现有证据检索、LangChain、Pydantic与版本化分析缓存，按项目并发处理50个已有示例。分析产物、证据和运行清单保存在各项目`prototype_runs/`，覆盖汇总见`data/newcomer_deep_guides_report.json`。文件引用错误会得到明确的安全修复反馈，不接受引用不匹配的结果。

流式助手绑定当前任务，发送问题时结合原始Issue、已有导读、相关源码、推荐及最多8条近期对话调用DeepSeek。没有配置时可显式使用资料助手。中断、异常和取消会清除半截回答，不把它加入后续模型上下文；支持重试、停止和清空。

## 实现与验证

前端：`web/index.html`、`web/app.css`、`web/app.js`，无前端构建依赖。服务入口：`serve.py`。安全展示适配：`gfi_prototype/portal.py`。HTTP与SSE：`gfi_prototype/portal_server.py`。

Windows下缓存文件被读取或扫描时可能短暂拒绝替换，原子写入使用独立临时文件和有界重试；技术匹配缓存按项目集中落盘，避免为每个任务对反复读写整份缓存。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
node tests/test_portal_frontend.mjs
node --check web/app.js
```

旧Streamlit入口仅保留为历史演示；产品界面以本HTML门户为准。更早技术文档中的“待实现”与旧覆盖数量是当时的历史记录，本页及最新运行清单为本轮实现状态。
