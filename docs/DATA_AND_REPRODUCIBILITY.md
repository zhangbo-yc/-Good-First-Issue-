# 数据与实验复现材料

## 源码与数据分发

仓库源码包括Python包、网页资源、兼容CLI、测试、依赖配置和结果报告。以下材料独立于Python安装包：

| 目录 | 用途 | 分发要求 |
| --- | --- | --- |
| data/ | 原始Issue、源码快照、索引、中文说明、分析与推荐 | 完整演示需提供对应数据包 |
| experiments/ | 冻结协议、逐题答案、评分与请求缓存 | 实验追溯需提供，保持路径和文件内容 |
| output/ | 最终分析报告、汇总及PNG方法图 | 保留比赛展示所用结果 |
| .env | 本机密钥 | 不公开提交，不打包 |

`.gitignore`排除data和experiments，避免把上游源码、数据库和付费缓存误当作普通源码提交。它们没有被删除。论文/比赛附件可提供独立数据压缩包，接收者应解压到同名目录；当前仓库不包含公开下载地址或自动下载逻辑。

## 复现约束

- 冻结实验使用固定源码版本及文件哈希。保留根目录研究脚本和JSON配置，不能仅为目录美观移动。
- 39题消融、34题完整样本控制实验和事后单案例分别说明，不混算独立任务量。
- 历史156份答案来自Python编排版本，不改称当前LangGraph重跑结果。
- 运行新方法需使用新版本与独立输出目录。模型评审属于辅助评价，不是人工金标准。
- 34题离线报告脚本仍引用已缺失的历史PPT；现有结果可阅读，重跑前需要恢复原追溯文件或记录配置更改。

## 源码安装与wheel

源码目录下可直接运行`python serve.py`或`python -m gfi_prototype`。`pip install --no-deps -e .`提供`gfi-portal`命令，先按requirements.txt安装运行依赖。

wheel包含`gfi_prototype`包、网页静态资源及检索依赖的`collect_gfi`兼容模块，不包含data、experiments、研究CLI与密钥。安装wheel后使用`gfi-portal --root <数据工作目录>`；工作目录需要包含`data/`，可选`.env`。查看本地研究结果仍需另附experiments/output。默认源码启动方式不变。
